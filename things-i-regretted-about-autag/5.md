# DRY master

## Why is it shit?
This is the main reason why this project has way more lines of code than it actually needs. There are things like this throughout the entire codebase:
```js
inquirer.prompt([
    {
        key: "file",
        value: "file"
    },
    {
        key: "ignore",
        value: "ignore"
    },
    {
        key: "mkdir",
        value: "mkdir"
    }
    /* rest of the options */
])
```

This is a terrible approach. Genuinely, I don't know why I didn't just use a simple array like ```["file", "ignore", "mkdir", ...]``` and map over it.

Look at this case too:
```js
if (anweser.lang === "en") {
    translate(anweser.data, {
        to: anweser.lang
    }).then(res => {
        console.log(`translate to english:\n${res.text}`)
    })
}
if (anweser.lang === "es") {
    translate(anweser.data, {
        to: anweser.lang
    }).then(res => {
        console.log(`translate to spanish:\n${res.text}`)
    })
}
```

And finally, this one:
```js
inquirer.prompt([
    {
        name: "paste",
        message: "Write a file to paste content"
    },
    {
        name: "copy",
        message: "Write a file to copy content"
    }
])
```
In this last case, I could have easily used a helper function that generates the object ```{name, message}``` based on a simple ```string[]```.

## How to stop being shit
The DRY principle exists for a reason. If you find yourself copying and pasting a block of code and only changing one or two strings (like `"en"` to `"es"`, or `"english"` to `"spanish"`), **stop writing immediately**. You are doing it wrong.

Whenever you see patterns repeating, use modern JavaScript array methods like `.map()` or create a simple dictionary (object lookup). 

For example, that terrible translation block could have been written in just a few lines using a language map:
```js
const langNames = { 
    en: "english", 
    es: "spanish" 
}

translate(anweser.data, { to: anweser.lang }).then(res => {
    console.log(`translate to ${langNames[anweser.lang]}:\n${res.text}`)
})
```

And for `inquirer`, a simple map loop over an array would have saved me hundreds of lines of boilerplate:
```js
const options = ["paste", "copy"].map(action => ({
    name: action,
    message: `Write a file to ${action} content`
}))
```

With this way less embarrassing to read years later.
