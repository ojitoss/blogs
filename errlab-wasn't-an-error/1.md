# Project structure

The general structure ignoring files or folders that not aport anything useful to analize is that:

```
class/
index.js
test.js
```

**class/**: In that folder is all the useful code for the lib and definitions of methods, every file is a ```.js``` file, where every of that files is a methods or class to a specific style of error (like legend, "block" or button) and the name of the file indicates the style of block that the file export.

**index.js**: Is the entry point of the package, its just an exported object that re-export the *class/* folder.

**test.js**: Although it's called *test* is actually an example file that uses Express framework..

The structure is pettry decent and I don't think that had overengineering, maybe the fact than every class is a file, but at least this add consistency and you exactly know where look for, it isn't like Autag that every file are splitted unnecessarily in two parts. Algthout had a file than the only thing it does is re-export in an object *class/* folder utilities, the main diference with Autag is that file is uneccesary because the make three re-export: ultity folder -> re-export file -> main file, how errlab being a library and not a CLI, this is the best practice to had claryfull what is the API that the target user will uses.
