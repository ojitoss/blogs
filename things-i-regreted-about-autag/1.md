# Why is this variable?

## Why is it shit?
With the rest of the things, I know I was trying to look like a professional programmer,
or maybe I just wrote pretty bad code at that age. But with this, genuinely, I
don't get what I was trying to do. Seriously, it's so pointless. My only
theory is that I thought this line of code was necessary for classes to work or
to be exported in Node.js. So, why does it hurt me so much? Basically, ahead
of each class, I added a variable called ```global_object```:
```js
let global_object = new Object()
class Some {}
```
Also, when I did this, I used ```module.exports = Some```. So with
that name referring to a global object, I'm sure I thought it was
necessary for exporting. Especially because, for some reason, I used the Object constructor 
instead of just ```{}```. I was trying to use decorators when they didn't even exist
(and honestly, they currently still don't even fully exist).

## How to stop being shit
Just don't add lines of code based on a "hunch." If you don't know exactly what a line does, look it up in the official docs first. Otherwise, you'll waste time writing pointless boilerplate that serves absolutely no purpose. Understand your tools before you code, or you'll end up with ghost variables haunting your repos.
